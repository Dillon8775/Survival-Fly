- Added /flightspeed command, which allows the player to change their flight speed!
- The player can also change their flight speed by using ALT + SCROLL on any gamemode (this is configurable, and by default is set only to creative and spectator mode).
- Added keybind for which key needs to be pressed in order to change flight speed.
- Added keybind to reset flight speed.
- Player can now just execute /flight and it will set their flight ability to whatever the opposite of their current flying ability is.
- Added button to configure survival fly.
