# Adds a **_/flight_** command for survival players.

### Currently compatible with Minecraft versions **1.21.2-1.21.5.**

---

# _/flight command!_
#### By default, _anyone_ can use this command. You can change this if you'd like.
### Command Usages:
#### /flight
#### /flight _**enable**_/_**disable**_ _*'target(s)'*_
#### (since: v1.0)

![/flight command in action.](https://i.imgur.com/oYBpxtu.gif)

---

# _/flightspeed command!_
#### Changes the flight speed of the target player.
### You can also use _ALT + SCROLL_ to increase/decrease your flight speed, and press B to reset your flight speed.
### Command Usages:
#### /flightspeed _set_ _**speed%**_ _*'target(s)'*_
#### /flightspeed _get_ _*'target'*_
#### /flightspeed _reset_ _*'target(s)'*_

#### (since: v1.2)

![/flightspeed command in action.](https://i.imgur.com/FqqNHPn.gif)

---

# _/flightstatus command!_
#### Shows whether or not the target player has flying abilities.
Command Usage: /flightstatus _*'target'*_
#### (since: v1.1)

![/flightstatus command in action.](https://i.imgur.com/d7b3E5h.gif)
