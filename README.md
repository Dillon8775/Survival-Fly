Adds a **_/flight_** command for survival players.

## Currently compatible with Minecraft versions **1.21-1.21.5.**

# FEATURES
- **_/flight_** command in survival/adventure mode (by default, __anyone__ can use the command).
![/flight command in action.](https://i.imgur.com/oYBpxtu.gif)

- **_/flightstatus_** command, which tells whether or not the player has flying abilities.
![/flightstatus command in action.](https://i.imgur.com/d7b3E5h.gif)

- Ability to change permissions for who can use the /flight command.
