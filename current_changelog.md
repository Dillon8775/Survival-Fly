# Survival Fly Version 1.3.2

## Survival Fly now requires [YetAnotherConfigLib](https://modrinth.com/mod/yacl) *(client-side only)*

## Changes
- `Enable Mod` option, which toggles `all Survival Fly features`.
- `Revamped config screen` w/ [YetAnotherConfigLib](https://modrinth.com/mod/yacl).
- Removed `Menu Button` option, and removed the `survival fly button on all screens`. Config now only accessible via [Mod Menu](https://modrinth.com/mod/modmenu) or [NeoForge's config system](https://neoforged.net/)
- Dropped `Forge` support.
