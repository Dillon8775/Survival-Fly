# Version 1.3.7
- Added an "allowmodification" argument to the flight speed command, which toggles whether all players can change their flight speed.
    - You can also change this value manually in the options file.
- Added a disclaimer in the mod, for cheaters.
- Now requires [DillonLib](https://modrinth.com/mod/dillon-lib) version 1.2.
- No longer requires YACL to run, and now uses Balm config system.
- Optimized lang.
